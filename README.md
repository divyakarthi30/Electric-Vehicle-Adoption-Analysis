# 🚗 ELECTRIC VEHICLE ADOPTION & INFRASTRUCTURE ANALYSIS

## 📘 Project Overview
The Electric Vehicle Adoption & Infrastructure Analysis project was developed to analyze global EV market trends, charging infrastructure growth, pricing patterns, and adoption behavior using data analytics and visualization techniques.

The project transforms raw EV data into meaningful business insights through Exploratory Data Analysis (EDA) and interactive Power BI dashboards. Different visualizations such as KPI cards, scatter plots, histograms, donut charts, line charts, and tree maps were used to identify market trends and infrastructure impact.

The dashboard provides insights into EV sales performance, charging station availability, government incentives, vehicle range distribution, and regional EV adoption patterns.

Overall, the project helps understand factors influencing EV adoption and supports data-driven business decisions for future EV market growth.

---

# 🎯 Objectives

- Analyze global EV adoption trends
- Study charging infrastructure growth
- Understand relationship between EV sales and infrastructure
- Create meaningful visualizations
